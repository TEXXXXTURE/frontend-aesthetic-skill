01 为什么 PROBLEM
趋向性 · 不是能力 AI 前端难看，是趋向问题。

模型输出趋近训练分布均值——"平庸但不出错"。审美在分布长尾的人，与均值输出之间存在结构性错位。

约束 · 不是形容词 好形容词拽不动模型。

"好看""高级"会被训练先验吞噬；token 级值域、白名单、禁区，才真正改变输出分布。

无缝隙 · 全覆盖 模型会用先验填补所有缝隙。

约束网络必须覆盖全部 8 个维度，不留一个让模型"自己发挥"的口子。

闸门 · 可量化 审美裁决权在人，机器只做可测检查。

L1 几何量化 → L2 参考对齐 → L3 人工评审，三层闸门各司其职。

02 约束网络 8 DIMENSIONS
  1. 1字体系统白名单 + 角色三分（display/body/mono）+ 高对比配对；禁 Inter/Roboto
  2. 2色板角色表背景/表面/边框/正文/强调五角色；主导色+锐利强调；禁紫渐变白底
  3. 3间距与网格8pt 网格遵守；列比显式不对称；clamp 字号梯度 3x+
  4. 4动效参数时长/缓动显式（0.8-1.4s）；聚焦高影响时刻；尊重 reduced-motion
  5. 5背景质感≥2 层质感；纯 CSS 绘制零外部资产；禁纯色平铺
  6. 6风格方向词一个词锁定气质；具象参考（印刷史/建筑/IDE 主题）
  7. 7结构与内容页面区块显式清单；demo 数据必须"活"；虚构数据标 illustrative
  8. 8可访问与交付语义 HTML / aria / 可见焦点；输出完整 + 8 维自检清单
机制：风格方向词 → Skill 展开 8 维约束模板 → 约束注入（system prompt / CLAUDE.md）→ 产物自检（8 维逐项）→ 量化闸门（L1/L2/L3）
